# 关于马斯克铁粉站

马斯克铁粉站（Musk Fans Hub）是一个中文 Elon Musk 资料整理与内容归档网站，网址为 [muskfans.cn](https://muskfans.cn)。

本站持续整理埃隆·马斯克在 Tesla、SpaceX、Neuralink、xAI、X 和 Optimus 等项目中的公开观点、演讲、访谈、推文以及相关事件，帮助中文读者更方便地查找原始信息、理解背景，并从长期脉络观察这些公司的发展。

## 这里有什么？

本站目前主要包含六类内容：

| 分类 | 内容 |
| --- | --- |
| [公司](/categories/companies/) | Tesla、SpaceX、Neuralink、xAI、X 和 Optimus 等项目与公司动态 |
| [周边](/categories/gossip/) | 个人经历、家庭、人物故事和其他相关信息 |
| [深度](/categories/long/) | 对技术、商业、管理和未来议题的较完整整理与分析 |
| [新闻](/categories/news/) | 值得记录的重要事件和最新进展 |
| [语录](/categories/quotes/) | 演讲、采访和公开谈话中的观点与原话整理 |
| [推文](/categories/tweets/) | 马斯克在 X 上发布的推文及其语境整理 |

你也可以从[分类页面](/categories/)按主题浏览，或从首页查看最新文章。

## 我们关注什么？

本站特别关注马斯克反复讨论的几个主题：

- 第一性原理、工程实践与产品开发
- 人工智能、机器人和 Neuralink
- 可重复使用火箭、火星与多行星文明
- 电动车、能源、自动驾驶和制造业
- 企业管理、人才、执行力与长期主义
- 人口、文明存续以及人类未来

这些内容不只记录一句名言，也尽量补充说话场景、时间、相关项目和后续进展，让观点放回原来的语境中理解。

## 内容说明

本站内容主要基于公开资料进行翻译、整理和编辑。引用马斯克的观点时，我们会尽量保留原意，并在文章中注明来源和时间；文章标题、摘要和分类由本站编辑，个别文章包含基于公开信息的背景说明或个人整理，不代表相关公司或埃隆·马斯克本人立场。

马斯克的观点和相关事实可能随时间变化。涉及投资、医疗、法律或其他重要决策时，请以官方公告、原始采访和专业机构信息为准，本站内容不构成任何建议。

## 为什么建立本站？

中文互联网上关于马斯克的消息往往分散在新闻、社交媒体和视频访谈中。本站希望把这些公开内容整理成一个可以检索、回顾和持续更新的中文档案库：既保存值得反复阅读的原话，也记录观点背后的工程和商业实践。

如果你发现文章中的来源、翻译或事实存在问题，欢迎通过项目的 [GitHub 仓库](https://github.com/wsgsc/wsgsc.github.io)提交反馈。
